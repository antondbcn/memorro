Esta aplicación web tiene el objetivo de facilitar el aprendizaje en el largo plazo de parejas de datos.
Su funcionamiento se basa, al igual que otras aplicaciónes como Anki, en mostrar tarjetas en el momento adecuado.
Sin embargo, el uso normal de una aplicación no permite sacar todo el provecho a ese mecanismo de la memoria y , por lo tanto, no hago mucho hincapié en ello.
Una ventaja sobre otras aplicaciones es que de forma transparente al usuario se van añadiendo tarjetas nuevas de forma natural. Igualmente, desaparecen del estudio si ya son sabidas.
